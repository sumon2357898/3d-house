# 🏠 3D 房子漫游 (Interactive 3D House)

用 **Three.js** 实现的可漫游 3D 房子，支持 **电脑 + 手机横屏**，手机带虚拟摇杆与陀螺仪转向。

## ✨ 功能

- **多房间**：客厅、厨房、卧室、卫生间
- **家具**：沙发、茶几、电视、落地灯、植物、橱柜、冰箱、灶台、餐桌椅、双人床、衣柜、马桶、洗手台等
- **电脑操作**
  - 点击开始，锁定鼠标
  - `WASD` / 方向键 移动
  - 鼠标环顾
  - `空格` 跳跃 · `Shift` 奔跑
- **手机操作（横屏）**
  - 左下角虚拟摇杆移动
  - **陀螺仪** 控制视角（需授权）
  - 无陀螺仪时：右侧屏幕滑动转向
  - 右侧按钮：跳跃 / 奔跑
  - 竖屏时提示“请横过来”
- 实时显示当前房间与坐标

## 🎮 使用说明

### 电脑
1. 打开页面 → 点击「点击开始」
2. WASD 移动，鼠标看四周

### 手机
1. **请横屏**使用（竖屏会提示旋转）
2. 点击「点击开始 / 授权陀螺仪」并允许运动与方向权限
3. 左手摇杆走路，转头看房间，右侧点「跳」「跑」

> iOS 需在用户手势里请求 `DeviceOrientationEvent` 权限，第一次会弹出系统授权框。

## 🚀 本地运行

```bash
# Python
python -m http.server 8080

# 或
npx serve .
```

访问 `http://localhost:8080`。  
手机调试建议用同一局域网 IP，或部署到 GitHub Pages 后用真机打开。

## 📦 技术栈

- Three.js r170（CDN + import map）
- 自定义第一人称控制（键盘 + 虚拟摇杆 + 陀螺仪）
- 纯静态页面，无构建步骤
